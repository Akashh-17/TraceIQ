# TraceIQ — Frontend

React dashboard for TraceIQ: audit log, detections, actor profiles, AI investigations,
user management and the integration guide.

**Stack:** React 19, TypeScript, Vite, Tailwind CSS v4, TanStack Query, Zustand, Recharts.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
```

The API URL is read from `VITE_API_URL` (defaults to `http://localhost:3000`).
See the [root README](../README.md) and [DEMO.md](../DEMO.md) for running the full stack.
